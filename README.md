# 🎭 Mafia Online — Обзор проекта

Веб-приложение для проведения настольной игры «Мафия» с друзьями на разных устройствах. Сайт выступает в роли автоматического ведущего, контролирует таймеры фаз (45 секунд на ночную роль), раздает роли и рассчитывает итоги ночи и дневного голосования.

## Архитектура и репозитории
Проект разделен на два независимых приложения:
1. **Frontend (`mafia-online-client`):** https://github.com/LimTFX/mafia-online-client
2. **Backend (`mafia-online-server`):** https://github.com/LimTFX/mafia-online-server

## Игровой процесс
* **Комнаты:** Создание приватных комнат с уникальным кодом и сохранением сессии в БД (игра не сбрасывается при перезагрузке страницы).
* **Порядок ночных фаз (по 45 секунд на каждую):** Любовница \(\rightarrow\) Доктор \(\rightarrow\) Мафия \(\rightarrow\) Детектив.
* **Общение:** Голосовое или текстовое обсуждение происходит на внешней площадке, сайт выполняет только роль ведущего.
